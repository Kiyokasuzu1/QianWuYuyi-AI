# QianWuYuyi-AI

一个探索 AI 人格、长期记忆与成长系统的实验项目。

## 项目目标

打造一个具有：

- 稳定人格
- 长期记忆
- 情绪状态
- 成长能力

的 AI 角色系统。

## 核心模块

### Persona System
人格系统

负责：
- 性格
- 语言习惯
- 行为模式


### Memory System
记忆系统

负责：
- 用户记忆
- 事件记录
- 长期关系


### Emotion System
情绪系统

负责：
- 当前状态
- 情绪变化
- 回复风格调整


## 技术方向

- AstrBot
- Python
- LLM
- Memory Database
