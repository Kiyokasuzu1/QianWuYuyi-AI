## 核心保护目标（测试直接守护的宪法条款）

1. **无虚构经历**（M1）：空输入 → 「正在积累中」；无来源数据被守卫拒绝；攻击测试 11/11 拒绝编造。
2. **IdentityCore 保护**（宪法第 4 章身份保护）：叙事文本不含名字/身份断言；快照 core_identity 字段与叙事分离；Prompt 顺序断言。
3. **治理链无旁路**（O1 架构保护第 8 条）：accept_experience 零调用；state_mutations/proposals 零增量；状态文件 hash 不变。
4. **可追溯**：每条叙事带 source_reference/timestamp/confidence/origin=assembled，可回查原始记录。
5. **幂等与有界**：同来源同 narrative_id；无 diff 不 append；快照数量封顶（max_snapshots）。

## 已知非阻断问题

1. **Python 3.11 与 3.14 注解语义差异**：`Optional` 未导入在 3.11 下运行时 NameError（已修复：`from __future__ import annotations`）；后续部署需保持 3.11 兼容性检查习惯。
2. **成长解释层（Growth Explainability）的 proposal 反查渲染**：已具备数据基础（快照含 record/proposal id），但尚未被真实治理事件端到端驱动验证——留待 v1.2.x 观察期。
3. **生产业务事件喂入 Host EventLog**：反思生产事件源的最后一根接线仍未接通（v1.1 已知缺口，非 v1.2 引入）。
4. **Agent Server**：远程代理因 token 未配置 fail-closed（与本版本无关的历史事项）。
